Noiser is a personal fork of [Seeker](https://github.com/jackBonadies/SeekerAndroid) for Android, with a built-in MP3 player. Most of the app comes from Seeker.

- Play songs while they download.
- Queue tracks, use repeat, and control playback from the lock screen.
- Reopen with your queue and current song saved, paused.
- Bookmark peer folders and download app updates from Settings.
- Search, sharing, downloads, uploads, and chat from Seeker.

## Install

[Download Noiser.apk](https://github.com/miacadaver/Noiser/releases/latest/download/Noiser.apk) · [Release notes](https://github.com/miacadaver/Noiser/releases/latest)

Requires Android 6.0 or newer. Install the APK and sign in to Soulseek. For later updates, use **Settings → Check for updates**.

## Limits

Streaming is MP3-only. Peers need to be online, and seeking is limited to audio already received. The saved song restarts from the beginning when you press Play.

This is a development build. [Report a bug](https://github.com/miacadaver/Noiser/issues).
